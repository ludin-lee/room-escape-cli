# Room Escape (CLI 방탈출)

![터미널 방탈출 게임을 만드는 개발자와 방탈출 아이디어 스케치](cover.png)

터미널에서 텍스트 명령으로 진행하는 1인용 방탈출 게임. 외부 의존성 없음 (Node.js 22+).

```sh
node bin/escape.js            # 바로 실행
npm link && escape            # 전역 명령으로 등록해서 실행
escape --list                 # 시나리오 목록
escape -s old-study           # 시나리오 지정 (생략하면 메뉴에서 선택)
escape --load s1              # 저장 슬롯에서 이어하기
escape --new                  # 자동 저장 무시하고 새로 시작
escape --fast                 # 타자 효과 끄기 (ESCAPE_FAST=1 도 동일)
escape --no-status            # 상단 상태 박스 끄기 (ESCAPE_NO_STATUS=1 도 동일)
npm test                      # 테스트
```

## 수록 시나리오

| id | 제목 | 제한 시간 | 방 / 퍼즐 |
|---|---|---|---|
| `old-study` | 낡은 서재 | 30분 | 4 / 7 |
| `midnight-ward` | 자정의 병동 | 20분 | 4 / 5 |
| `observatory` | 폐쇄된 천문대 | 45분 | 7 / 9 |
| `jigsaw` | 직쏘의 게임 | 60분 | 8 / 14 · **실수하면 즉시 게임 오버** (난이도 최상) |
| `zombie-street` | 죽은 자들의 거리 | 45분 | 7 / 11 · **아이템 조합** 5종, 함정 3종 |

## 명령어

| 명령 | 예시 |
|---|---|
| 보기 / look | `보기` |
| 조사 / examine | `조사 책상`, `x desk` |
| 줍기 / take | `줍기 일기장` |
| 사용 / use | `사용 열쇠 문`, `열쇠를 문에 사용`, `use key on door` |
| 입력 / enter | `입력 731 금고`, `입력 7-3-1` |
| 이동 / go | `이동 복도` |
| 돌리기 / 당기기 / 열기 / turn | `돌리기 밸브`, `열기 23번상자` (아이템 없이 장치를 직접 조작) |
| 조합 / 합치기 / combine | `조합 방망이 못`, `조합 소독약과 붕대` (가방의 두 물건을 합친다. 순서 무관) |
| 가방 / inventory | `가방`, `i` |
| 힌트 / hint | `힌트` (남은 시간 2분 차감) |
| 저장 / 불러오기 | `저장 s1`, `불러오기 s1` (기본 슬롯 `auto`) |
| 종료 / quit | `종료` |

저장 파일은 `~/.room-escape/saves/<슬롯>.json` 에 저장됩니다 (`ESCAPE_SAVE_DIR` 로 위치 변경 가능).

### 상단 상태 박스

터미널 위 5줄에 현재 위치·남은 시간·보이는 것·가방을 고정 표시하고, 게임 출력은 그 아래에서만 스크롤됩니다. 남은 시간은 1초마다 갱신되며 5분 이하면 노란색, 1분 이하면 빨간색으로 바뀝니다. TTY 가 아니거나 화면이 너무 작으면 자동으로 꺼집니다.

```
┌─ 직쏘의 게임 ──────────────────────────────────────┐
│ 위치  냉동창고                       남은 시간 41:07 │
│ 보임  온도계, 07번상자, 12번상자, 19번상자, 23번상자… │
│ 가방  철사, 봉투, 토치                                │
└────────────────────────────────────────────────────┘
```

### 게임 오버 (함정)

`jigsaw` 같은 시나리오에는 시간 초과 외에 **즉시 패배**하는 함정이 있습니다. 자물쇠 오답 횟수 제한, 잘못된 문 선택, 장치 조작 순서 실수 등이 해당합니다. 오답이 시간을 깎기만 하는 자물쇠도 있으니 메시지를 잘 읽으세요.

함정으로 죽으면 `다시 도전할까요? (Y/n)` 를 묻습니다. 수락하면 **죽기 직전 턴**으로 돌아가고, 대신 남은 시간이 3분(시나리오의 `retryPenaltySec`) 줄어듭니다. 자물쇠 오답 횟수는 초기화됩니다. 시간 초과는 재도전할 수 없습니다.

### 자동 저장과 이어하기

- 매 턴이 끝날 때마다 `auto` 슬롯에 자동 저장됩니다. `종료` 나 Ctrl+C 로 나가도 진행 상황이 남습니다.
- 다시 실행하면 진행 중인 게임이 있을 때 `이어할까요? (Y/n)` 를 묻습니다. `-s` 로 시나리오를 지정한 경우 그 시나리오의 자동 저장만 묻습니다.
- 클리어하거나 시간이 초과되면 `auto` 슬롯은 지워집니다.
- `escape --new` 는 자동 저장을 무시하고 새로 시작합니다. 파이프 입력(비 TTY)에서는 묻지 않고 항상 새로 시작합니다.

## 새 시나리오 추가

`src/content/scenarios/<id>/scenario.json` 을 만들면 자동으로 목록에 뜹니다. 형식과 규칙은 [DESIGN.md](DESIGN.md) 5장을 보세요. 로드 시 참조 무결성 검사를 통과해야 하며, `test/walkthrough.test.js` 에 정답 명령 시퀀스를 추가하면 풀 수 있는 방인지 테스트가 보장합니다.
